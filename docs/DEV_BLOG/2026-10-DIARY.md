# October 2026 Development Diary

## Overview

Cross-platform replay validation.

## 2026-10-08 — Native replay test jobs

- Prepared explicit Linux x86_64 and Windows x86 replay jobs. Windows uses the
  existing Win32/DirectX8 build path, not the unfinished 64-bit SDL3 port.
- Inputs are encrypted and fetched from a draft release; the key is an Actions
  secret. Source edits, retail game data, accounts, and saves are not committed
  with the CI bootstrap. Accounts and saves are excluded from the test payload.
- Replay success requires recorded completion and exact agreement with all
  populated-world reference samples. Diagnostics are encrypted before upload.
- The first jobs reached GitHub but the read-only token could not list the
  draft input. A broader token permission was rejected before push. The
  revised job retains read-only permission and requests the known asset ID.
  Checkout does not persist the token.
- Native build/replay results are pending. Live networking, rendering, input,
  physical hardware behavior, and the modern Windows port remain unverified.
