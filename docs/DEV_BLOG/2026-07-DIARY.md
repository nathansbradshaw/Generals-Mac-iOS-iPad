# July 2026 Development Diary

## Overview

GeneralsOnline friends-scale integration and cross-platform multiplayer work.

## 2026-07-12 — GeneralsOnline server connection test

- Added a Test Connection action beside the persistent GeneralsOnline server
  address in Extra Options.
- The action validates the typed URL, probes the backend `ServiceConfig`
  endpoint without saving, uses a five-second timeout, and distinguishes HTTP
  failures from network, TLS, firewall, and local-network failures.
- The control is hidden when `SAGE_GENERALS_ONLINE` is disabled, prevents
  duplicate requests while a test is pending, and the macOS GeneralsXZH build
  passes. Physical-device and in-game feedback validation remains.

## 2026-07-11 — First complete GeneralsOnline Mac↔Mac match

- Completed the full self-hosted two-client flow: login, host/join, ready,
  direct ICE mesh, match start, gameplay, results, and clean lobby return.
- Fixed the missing `NextGenTransport` selection, several null legacy GameSpy
  assumptions, and a 64-bit lobby selection-buffer crash.
- Started the next milestone: configuring the iOS build with
  `SAGE_GENERALS_ONLINE=ON`; it now produces an ARM64 iOS executable with the
  complete WebSocket + GameNetworkingSockets/ICE dependency graph.
- Added a Phase 5 requirement for one persistent self-hosted server-address
  setting shared by macOS, iOS, Linux, and Windows; the environment variable is
  retained as an automation/deployment override.
- Implemented the shared persisted `network.service_url` core and common URL
  validation/precedence, then exposed it in Extra Options with a native text
  field and malformed-URL feedback. macOS and iOS builds pass; an active
  connection-test action remains.
